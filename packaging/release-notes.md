## Download

**Windows:** download **PenguinViewer-Setup.exe** below and open it. Windows may say it "protected your PC" because the app isn't signed yet: click **More info > Run anyway**.

**Linux** (Ubuntu 22.04+, Fedora, Mint, Arch, ... on 64-bit Intel/AMD): paste this in a terminal:

```
curl -fsSL https://github.com/Abdullahalmutairi97/Penguin-Viewer/releases/latest/download/install.sh | sh
```

or download **penguin-viewer-linux-x86_64.tar.gz**, unpack it and run `sh install.sh`. No sudo needed.

Then right-click any picture or video > **Open with** > **Penguin Viewer**.
